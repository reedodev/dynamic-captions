# 내 손글씨를 자막 글꼴로 쓰기

## 결론
- **영상에 실제로 나오는 글자만 쓰면 가능합니다.** 한 영상에 나오는 서로 다른 글자는 보통 100~250자입니다(추정).
- 한글 전체(11,172자)를 직접 쓰는 방식은 현실적으로 어렵습니다. 전체 글꼴이 필요하면 아래 '대안'의 유료 서비스가 자음·모음을 조합해 만들어 줍니다.
- 이 도구는 **쓴 글자만** 글꼴에 넣습니다. 쓰지 않은 글자는 글꼴에 없으므로 기본 글꼴로 대신 나옵니다(크롬에서 확인함. 대신 나오는 글자는 크기와 모양이 달라 어색할 수 있어서, 가능하면 영상 글자를 모두 쓰는 것이 좋습니다).
- 글꼴 모양은 쓴 필기 품질 그대로 나옵니다. 흔들린 선은 흔들린 대로 들어갑니다.

## 사용 순서
1. **시트 만들기** (영상 단어 파일에서 필요한 글자만 모아 칸 시트를 만듭니다)
   ```
   node scripts/handwriting-template.mjs --words words.json --out 작업폴더\tpl
   ```
   - `--text 대본.txt` 도 가능. 더 넣을 글자는 `--extra "가나다"`, 문장부호를 모두 넣으려면 `--all-punct`.
   - 숫자 0~9는 기본으로 들어갑니다(`--no-digits`로 끔). 문장부호는 `. , ? ! % ~` 중 대본에 나온 것만.
   - 결과: `sheet-01.png` 등(A4 세로 300dpi)과 `layout.json`. 한 장에 80칸.
2. **쓰기**: 시트를 A4로 인쇄해 검은 펜으로 씁니다. 태블릿이면 시트 그림을 배경으로 깔고 검은 펜으로 쓴 뒤, 모서리 네모가 보이게 통째로 저장/캡처합니다.
   - 한글은 칸을 크게 채워 쓰고, 숫자·문장부호는 칸 아래쪽 가로 줄에 맞춥니다.
   - 하늘색 안내선과 회색 작은 글자는 자동으로 걸러집니다(검은 펜만 남김).
3. **사진·스캔**: 밝고 평평하게, 그림자 없이, 네 모서리 검은 네모가 모두 보이게 찍습니다. 시트 순서대로 파일을 준비하고, 이름에 `sheet-02`처럼 번호를 넣으면 순서가 바뀌어도 맞춰 줍니다.
4. **글꼴 만들기**
   ```
   python scripts/handwriting-font.py --layout 작업폴더\tpl\layout.json --scans 사진1.jpg 사진2.jpg --out my-hand.ttf --name MyHand
   ```
   끝에 JSON으로 '들어간 글자'와 '빠진 글자'가 나옵니다. 빠진 글자는 안 쓴 칸입니다. 다시 써서 그 시트만 다시 찍어도 되지만, 시트 한 장을 다시 돌리면 그 장의 글자가 모두 새로 만들어집니다(여러 장은 모두 한 번에 넣으세요). 문제가 있으면 `--debug-dir 폴더`로 펴 놓은 시트 그림을 확인합니다.
   - 필요: fontTools, opencv-python, numpy.
5. **자막에 쓰기**: 자막 스킬의 `--font my-hand.ttf` 옵션으로 지정합니다. 합성 글꼴(54자)로 시험했을 때 쓴 글자는 손글씨로, 쓰지 않은 글자는 Pretendard로 자동 대체되는 것을 시안 그림으로 확인했습니다(글꼴이 달라 크기·높이가 조금 다르게 보입니다). 예시:
   ```
   node scripts/make-captions.mjs --words words.json --font my-hand.ttf ...
   ```
   옵션이 아직 없으면, 웹 페이지에서 `@font-face { font-family: MyHand; src: url("my-hand.ttf"); }` 로 직접 쓸 수 있습니다(크롬에서 한글이 그려지는 것을 확인함).

## 걸리는 시간(추정, 실제로 재 보지 않음)
- 글자 한 칸 쓰는 데 5~10초로 보면 150자는 15~25분, 사진 찍기·정리 약 10분. 글꼴 만들기는 컴퓨터에서 몇 초~1분(합성 시험에서 54자 약 몇 초).

- 크몽 글랩폰트 : 2,780자 770,000원, 11,172자 1,540,000원, 상업적 이용 가능, 제작 15일(판매자 안내). 출처: https://kmong.com/gig/730976

- 가격·약관은 바뀔 수 있으니 결제 전에 직접 확인하세요. 영상 자막처럼 돈 버는 용도라면 **이용 범위(상업용)** 를 꼭 확인해야 합니다.

## 법적·개인정보 메모
- 본인 손글씨만 사용하세요. 타인 글씨 사진을 글꼴로 만들면 안 됩니다.
- 글꼴 파일을 남에게 주거나 팔 경우 라이선스(사용 범위)는 직접 정하세요. 이 도구가 만든 파일은 사용자 본인의 글씨입니다.
- 외부 서비스에 사진을 올리면 그 서비스가 보관합니다(글씨공방은 내려받은 날부터 30일 후 삭제한다고 안내). 이 도구는 모두 PC 안에서만 동작합니다.

## 정직한 상태 표
| 항목 | 상태 |
|---|---|
| 시트 만들기(크롬 렌더, 8×10칸, 정합 표시) | 시험함: 54자 1장 생성, 눈으로 확인 |
| 합성 사진(회전·원근·잡음·얼룩 JPG)으로 글꼴 생성 | 시험함: 53자 생성, 안 쓴 1칸이 '빠진 글자'로 나옴 |
| 생성 글꼴로 문장 그리기(Pillow, 크롬 @font-face) | 시험함: 기준선·간격 정상, ㅇ·ㅎ 등 구멍 정상. 아주 가는 선은 약간 더 가늘어짐 |
| **실제 사람 손글씨, 실제 휴대폰 사진, 인쇄·스캔** | **시험 못 함** |
| 여러 장 시트(80자 초과) | 시험 못 함(코드는 지원) |
| 어두운 방·그림자·접힌 종이 | 시험 못 함. 모서리 인식이 실패하면 오류로 멈춥니다 |
| 자막 스킬 `--font` 연결 | 합성 글꼴로 확인함(쓴 글자는 손글씨, 나머지는 Pretendard로 대체). 실제 손글씨 글꼴로는 시험 전 |
| 가는 펜·연한 필기 | 약함. 검은 굵은 펜 권장 |
| 한글 11,172자 전체 | 지원 안 함(의도한 범위) |

## 영상 한 편 분량 시험 (2026-10-25)
- 이 사용법 영상의 자막 글자로 쓰기 시트를 만들었더니 시트 4장·294칸이 나왔습니다(숫자와 문장부호 포함).
- 손글씨풍 글꼴로 칸을 채운 합성 사진 4장(약 5%는 일부러 비움)으로 글꼴을 만들었더니 278자가 들어갔고, 빠진 16자는 정확히 보고됐습니다.
- 그 글꼴을 --font로 주고 자막을 그려 보니 쓴 글자는 손글씨로, 빠진 글자는 Pretendard로 나왔습니다.
- 이것은 합성 시험입니다. 사람이 쓴 실제 사진으로 하는 시험은 아직 하지 않았습니다.
